# Godot

- `addons/storycreep/` — the Godot editor plugin and runtime, in pure GDScript. Licensed under MIT (see [`addons/storycreep/LICENSE`](addons/storycreep/LICENSE)) so that games can include it without any obligation; the rest of the repository is AGPL-3.0-only.
- `example/` — an example game that wires the runtime to a dialogue UI.

See PRD §8 for the addon's design.
